# Meeting Notes

## Agreements

**Workshop not Hackathon**

The Event will be a workshop both in name and content. A hackathon within only one day, even if there is a lot of time, will likely not give participants enough time to build a proper project.

It is also unlikely that enough software developers attend, who have the skills to properly participate in such a competition, especially if there is no prize money on the line that could attract participants from abroad.

**Data not crypto**

The branding needs to disassociate the event from get-rich-quick schemes that try to sell a worthless product. This is for the most part something that [[partners/data/partners/Klarwerk|Klarwerk]] needs to figure out internally first, before we can plan the exact branding for the event.

**Funding through the university or partners**

As [[partners/data/partners/Klarwerk|Klarwerk]] is accredited by the university, we might receive enough funding for most of the event. Securing that funding is very important, since the industry seems to have little interest in investing money in events and marketing.

**Outreach over [[partners/data/partners/Klarwerk|Klarwerk]]-email**

Any outreach that is done should be done over [[partners/data/partners/Klarwerk|Klarwerk]]'s domain. This will simplify CRM and allow for a more organized approach to outreach.
